# Báo cáo và trình bày

S1–S3 đã có baseline, Optuna/logging, đánh giá holdout và hai hình. Báo cáo 8–12 trang, slide
5–8 trang hoặc một trang tóm tắt và hướng dẫn demo 5–7 phút thuộc S4.

Chỉ đưa bảng/hình vào báo cáo khi đã được sinh từ log thực nghiệm.
Kết quả CV Optuna lấy từ `results/trials.csv` và `results/best_config.json`.
Kết quả holdout ở `results/final_metrics.json`; hai PNG và bảng so sánh ở `figures/`.
README đã ghi nhận lựa chọn theo CV, kết quả test và giới hạn. Báo cáo/slide/demo S4 chưa triển khai.
